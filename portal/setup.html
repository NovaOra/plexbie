PlexbieFirst-time setup

Enter the setup code

So that only you can set Plexbie up, it printed a code in its log when it started. In Unraid, click Plexbie's icon on the Docker tab and choose Logs; it's the line that starts Setup code:.

Connect your Discord bot

Plexbie talks to your household through a Discord bot you own. Making one takes about two minutes.

Moving from another Plexbie? Bring its settings

Pick the old .env file and every setting in it is filled in here, ready to check on each step. Ports and folder paths stay as this install's own.

  1. Open the Discord Developer Portal and press New Application. Call it Plexbie.
  2. Go to Bot on the left. Press Reset Token, then Copy.
  3. On that same page, under Privileged Gateway Intents, turn on Server Members Intent. Press Save Changes.
  4. Still on the Developer Portal: under Installation set Install Link to None and save, then on Bot turn off Public Bot and save. Only you can add Plexbie to servers then.
  5. Paste the token here and press Check.

Add the bot to your server

Opens Discord. Pick your server and press Authorize. Then come back here and press Refresh.

Add Plexbie to my server

New server, or starting fresh? Plexbie can set it up: a Plexbie category with #new-on-plex, #plex-stats, a private #plexbie-admin and a Watch Party voice channel; the Plexbie Admin, Plex Member and New on Plex roles; the stats boards; and a "ping me for new arrivals" button. Anything already there by those names is reused. Then everything below is filled in.

Give yourself the Plexbie Admin role afterwards (Server Settings → Members) to see #plexbie-admin.

Don't see a channel or role? Make it in Discord, then press Refresh above. For the member role, drag Plexbie's own role above it in Server Settings → Roles so Plexbie is allowed to hand it out.

Connect your Plex server

Sign in with the Plex account that owns the server. Plexbie keeps the key it gets and uses it to invite and look after your household.

Or paste the address and token yourself
  1. Open Plex in a browser and sign in.
  2. Open any movie, press ⋯ → Get Info → View XML.
  3. In the address bar of the page that opens, copy everything after X-Plex-Token=.

Plex username and password rarely needed

Sign in with Plex above already lets Plexbie invite people, remove them and see who your server is shared with. These are only a fallback if your Plex token can't do that (a token copied from a server rather than from signing in, say).

Your other apps

All optional. Add the ones you run; each one turns on more of Plexbie. Use the address Plexbie's server can reach, like http://192.168.1.10:8989.

Your website

Plexbie's website is already running at this address. These are only needed once you share it outside your home.

Your household's Plexbie goes at plexbie.your domain. Point that name at this server (port 7979) in your Cloudflare tunnel or reverse proxy, then check it below.

Use a different address

For a name you already use, a Tailscale address (like server.tail1234.ts.net), or a dynamic-DNS name.

Leave it empty and links use whatever address people open the site with. Set it once you put the site behind a domain so invite links and sign-in always use the right name.

Your website's Privacy and Terms pages name you as the person who runs it, and tell people where to write. Without these they say "its owner" and "an admin".

"Log in with Discord" on the website optional

"Sign in with Plex" works without this. To also let people log in with Discord:

  1. In the Developer Portal, open your Plexbie app → OAuth2.
  2. Under Redirects, add exactly, and save. If you change your public address later, add the new one there too (Manage → Health tells you if it's missing).
  3. Press Reset Secret, copy it, and paste it below.
